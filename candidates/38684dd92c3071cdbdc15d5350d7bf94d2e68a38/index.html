    Portfolio Breakdown

    Understand what you own, how it is allocated, and how a proposed contribution would change it. Portfolio Breakdown runs locally, in a standalone window or in your browser. It supports current holdings, hierarchical categories, ETF exposure and planning; it does not execute trades or maintain tax accounts.

    Start with installation, then explore the demo or create an empty portfolio. For an existing holdings report, use the reviewed import.

    Which documentation applies?

    Each built page identifies its source commit, application package version and channel. Development follows ongoing work. Candidate and release copies refer to fixed source commits. Use the help linked by your installed version; a newer development guide may describe different controls.

    This guide covers the v1 feature set, including holdings import and extended ETF support. It does not describe the separate futures sandbox. A package version alone may be shared by several candidates: the source commit distinguishes them.
